# Three_Phase_EV_Infra_Planning

Code for phase I and phase II: Main_Code_Phase1-2.ipynb

Code for phase III: Main_Code_Phase3.ipynb

Datasets for all phase I, phase II, and phase III are included.

# The experiments are provided in the later revision Rev1_June2025

In Experiment 1, we fix the number of ports at each newly deployed charging station to six and assume a total budget of $1 million. 

Experiment 2 introduces flexibility in station sizing by allowing the number of ports to vary between 2 and 16 while keeping the budget fixed at $1 million. This setup explores how adaptive sizing can improve deployment efficiency under the same financial constraints.

In Experiment 3, we retain the flexible port configuration from Experiment 2 but reduce the available budget to $0.25 million. This experiment simulates a resource-constrained deployment scenario and evaluates how charger placement adapts under tighter funding limits. 

All experiments focus exclusively on planning Level 2 chargers (7.2 kW and 14 kW).
